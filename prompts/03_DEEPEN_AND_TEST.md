# G2–G3 — Module deepening and evidence

Use only team-selected ideas from `selection/FOCUS_SET.json`. Convert useful parts into module cards rather than forcing one complete Agent solution to win. For every module require equations/algorithm, data and parameter-estimation path, baseline, falsification test, failure modes and integration interface.

Use `evidence_architect` to define experiment manifests, metrics, splits, seeds, sensitivity, ablation and constraint checks. Use `experimenter` only after the plan is approved. Preserve failed runs. Register paper claims and evidence with `tools/harness.py claim-add` and `evidence-add`. Do not select a module on narrative appeal alone.
