# Targeted dispute resolution

Read one unresolved entry from `disputes/DISPUTE_REGISTER.json`. State the exact observation that would resolve or narrow it, then choose the cheapest reliable resource: local experiment, targeted specialist through the active runtime, independent Pro review, faithful/Lite verifier, or optional API burst. Complete only that dispute. Record artifacts and resolve it with `tools/harness.py dispute-resolve`; otherwise leave it open with a narrower next test.
