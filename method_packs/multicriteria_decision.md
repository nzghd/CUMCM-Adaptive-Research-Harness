# Multi-Criteria Decision Analysis

**Use when:** the task is genuinely ranking/evaluating alternatives under explicit
criteria, not when a predictive or mechanistic model is required.

**Formulation:** define alternatives, criteria direction, normalization, weights,
aggregation and tie/rank rule.

**Baseline:** equal-weight transparent ranking.

**Required diagnostics:** weight perturbation, normalization alternatives, rank
reversal, criterion redundancy, missing criteria and stakeholder interpretation.

**Common traps:** AHP/TOPSIS used by reflex; subjective weights without provenance;
rank presented as prediction; no rank-stability analysis.
